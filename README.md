# Travel Agency React

A premium Travel Agency Website built with React 19 + Vite.

## Tech Stack

- React 19
- Vite
- React Router DOM
- Axios
- React Hook Form
- Zod
- Framer Motion
- Swiper
- React Icons
- Chart.js
- React Hot Toast
- CSS3

---

## Requirements

Node.js 22+

npm 10+

---

## Installation

```bash
npm install
```

---

## Run Development

```bash
npm run dev
```

---

## Build

```bash
npm run build
```

---

## Preview

